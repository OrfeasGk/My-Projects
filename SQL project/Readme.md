Project Introduction: SQL Database Design for Rental Property Management

This project involved the design and implementation of a relational SQL database tailored for a rental property management system. The database was structured to efficiently organize and manage key information related to residential leasing. It consists of five interconnected tables: Tenants, Owners, Apartments, Rentals, and Reviews. Each table was carefully modeled to reflect real-world entities and relationships within the rental ecosystem. The objective was to create a scalable and normalized schema that supports robust querying, ensures data integrity, and facilitates future integration with web or data analytics applications.
In addition to the database design, we co-authored a research paper exploring the role of blockchain technology and smart contracts in enhancing security and automation within digital rental systems. The paper examines how decentralized ledgers and self-executing agreements can be integrated into database systems and explores the role and applications of Smart Contracts
